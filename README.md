# NAREVO

Telegram-магазин официальных цифровых кодов подписки с Mini App, личным кабинетом и админ-панелью.

## Быстрый запуск

1. Скопируйте `.env.example` в `.env` и заполните значения.
2. Создайте ключ: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`.
3. Запустите `npm.cmd start`.
4. Напишите боту `/start`. Основной магазин работает полностью внутри Telegram и не требует сайта.

После `/start` бот включает постоянную компактную клавиатуру под полем ввода: каталог, кабинет, покупки, пополнение и поддержка. Нажатое пользователем сообщение удаляется, а текущая карточка меню обновляется на месте.

Чтобы узнать свой Telegram ID, отправьте боту `/id`, затем внесите число в `ADMIN_IDS` и перезапустите бот. `PUBLIC_URL` нужен только для дополнительного графического Mini App и может пока оставаться локальным.

Для локального демо откройте `http://localhost:3000/?demo=1`. Реальные платежи намеренно не имитируются: пополнение подтверждает администратор после сверки с выбранным легальным платёжным провайдером.

## Безопасность

- Telegram `initData` проверяется по HMAC на сервере.
- Коды шифруются AES-256-GCM и никогда не отправляются в каталог.
- Админские права задаются только через `ADMIN_IDS` на сервере.
- Все изменения баланса и выдачи фиксируются в журнале.
- Для продакшена обязательны HTTPS, резервные копии, ограничение доступа к серверу и внешний платёжный провайдер с webhook-подписью.

Название Gmail допустимо только для официального или действительно совместимого продукта. Не используйте магазин для продажи аккаунтов, паролей или обхода правил сервисов.

## Платежи

В меню доступны четыре способа: CryptoBot, Heleket, СБП · 1% и СБП · 14%. Минимальное пополнение — 50 ₽. Комиссия СБП добавляется поверх суммы зачисления: при вводе 100 ₽ счёт составит 101 ₽ для СБП · 1% или 114 ₽ для СБП · 14%, а на баланс поступит 100 ₽. СБП · 1% создаёт автоматическую ссылку TelegaPay и проверяет оплату по API; для него требуется `TELEGAPAY_API_KEY`. СБП · 14% создаёт ручную заявку администратору. CryptoBot создаёт счёт в рублях с оплатой только через USDT. Heleket создаёт рублёвый счёт и предлагает покупателю доступные в магазине Heleket криптовалюты и сети.

Для CryptoBot:

1. В `@CryptoBot` откройте Crypto Pay → My Apps и создайте приложение.
2. Добавьте полученный токен только в переменные хостинга: `CRYPTOPAY_TOKEN`.
3. Используйте приложение, созданное в основном `@CryptoBot`: код принудительно работает с mainnet.
4. В настройках приложения включите Webhooks и укажите `https://ВАШ-ПУБЛИЧНЫЙ-ДОМЕН/api/payments/cryptobot/webhook`.

Токен Crypto Pay нельзя добавлять в GitHub или отправлять в переписке. Счета CryptoBot нельзя подтверждать вручную из админ-панели.

Для Heleket:

1. Создайте магазин в личном кабинете Heleket.
2. В настройках магазина скопируйте UUID мерчанта и платёжный API-ключ.
3. Добавьте их только в переменные хостинга: `HELEKET_MERCHANT_ID` и `HELEKET_PAYMENT_API_KEY`.
4. Перезапустите бота. Покупатель выбирает криптовалюту и сеть уже на защищённой странице Heleket.

Платёжный API-ключ Heleket нельзя добавлять в GitHub или отправлять в переписке. Баланс зачисляется только после ответа Heleket со статусом `paid` или `paid_over`, совпадения UUID счёта, суммы и валюты RUB. Повторная проверка одного счёта не начисляет деньги второй раз.

Цвета платёжных кнопок заданы средствами Telegram: CryptoBot — синий, Heleket — красный, СБП RUB — зелёный. Администратор с Telegram Premium может отправить боту `/emoji`, а затем три премиум-эмодзи одним сообщением в порядке CryptoBot, Heleket, СБП. Бот сам сохранит их ID. Также ID можно задать переменными `CRYPTOPAY_BUTTON_EMOJI_ID`, `HELEKET_BUTTON_EMOJI_ID` и `SBP_BUTTON_EMOJI_ID`. Без сохранённых ID используются обычные совместимые символы.

## Правила

В меню бота есть простой текстовый раздел «Правила»: конфиденциальность, условия покупки и выдачи, возвраты и правила поддержки. Отдельный сайт и реквизиты продавца для показа этих текстов не требуются.
