# NAREVO

Telegram-магазин официальных цифровых кодов подписки с Mini App, личным кабинетом и админ-панелью.

## Быстрый запуск

1. Скопируйте `.env.example` в `.env` и заполните значения.
2. Создайте ключ: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`.
3. Запустите `npm.cmd start`.
4. Напишите боту `/start`. Основной магазин работает полностью внутри Telegram и не требует сайта.

Чтобы узнать свой Telegram ID, отправьте боту `/id`, затем внесите число в `ADMIN_IDS` и перезапустите бот. `PUBLIC_URL` нужен только для дополнительного графического Mini App и может пока оставаться локальным.

Для локального демо откройте `http://localhost:3000/?demo=1`. Реальные платежи намеренно не имитируются: пополнение подтверждает администратор после сверки с выбранным легальным платёжным провайдером.

## Безопасность

- Telegram `initData` проверяется по HMAC на сервере.
- Коды шифруются AES-256-GCM и никогда не отправляются в каталог.
- Админские права задаются только через `ADMIN_IDS` на сервере.
- Все изменения баланса и выдачи фиксируются в журнале.
- Для продакшена обязательны HTTPS, резервные копии, ограничение доступа к серверу и внешний платёжный провайдер с webhook-подписью.

Название Gmail допустимо только для официального или действительно совместимого продукта. Не используйте магазин для продажи аккаунтов, паролей или обхода правил сервисов.
